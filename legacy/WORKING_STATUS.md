# Bridge Interactive: состояние разработки

Это рабочее дерево, не подтверждённый релиз. Cinema 4D S24.037 недоступна в этой среде: ToolData, отрисовка, клики, изменение mesh/тегов и Undo/Redo не проверены в реальном приложении. До релиза необходимо выполнить `c4d_acceptance/run_in_c4d.py` в Cinema 4D и отдельное интерактивное тестирование.

В геометрическом ядре добавлены PATH с Bézier/минимальным скручиванием и SURFACE; на ограниченных закрытых и открытых тестовых контурах выполнялось численное сравнение с Blender 5.2.4 в фоновом режиме. Это не подтверждение полного совпадения. Данные тесты не запускают Cinema 4D. Различные числа вершин контуров всё ещё создают отличную от Blender топологию.

Новые UV-корнеры для отдельных и парных мостов по возможности интерполируются из соседних полигонов, с учётом разрывов по рёбрам; при отсутствии соседних UV применяется отдельный остров. Реализация проверена только на синтетических данных и имитации API.

Добавлен прототип последовательного и циклического режима по группам граней. Он отклоняет операции с невалидной топологией; режим для более чем двух граничных цепочек рёбер ещё отсутствует. Для последовательного Merge равных по размеру граней добавлена экспериментальная последовательная сварка; сохранение весов и отклонение непредставимых в C4D свободных рёбер проверены лишь на имитации API. Нельзя считать функционал полностью эквивалентным Blender. Возможны другие непроверенные ошибки и ограничения.

Другое необходимое: уникальный зарегистрированный ID; в данный момент локальный тестовый `1000002`. Корректный предпросмотр исходных граней, предназначенных к удалению, ещё не обеспечен. N-gons, активные Fields и часть типов тегов намеренно отклоняются во избежание повреждения данных.

Автономные тесты: `for t in test_*.py; do python "$t" || break; done`. Эталонные сравнительные тесты для Blender находятся в `blender_*_probe.py` и зависят от отдельного локального Blender Python runtime. Тесты не являются заменой проверки в Cinema 4D.

В код добавлен экспериментальный Shift + перетаскивание для выбранного параметра с относительными событиями Cinema 4D; отмена Escape проверена на имитации событий. Не проверено, предотвращает ли этот механизм упор указателя в край экрана в реальной S24.

Для контуров разного размера подготовлен **отдельный невстроенный прототип** `unequal_prototype.py`: разбиение, близкое к Blender, и деление рёбер. На одном примере треугольного и четырёхугольного контуров совпали числа граней и позиции вершин в Linear/Path/Surface при 1–3 разрезах. Требуются разнообразные эталонные сцены, корректное добавление переноса UV/весов и интеграция в плагин; пока рабочее ядро продолжает использовать прежнюю схему.
