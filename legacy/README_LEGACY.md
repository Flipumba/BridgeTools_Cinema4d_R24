# Архив предыдущей экспериментальной версии

Эти файлы — черновики прошлого агента. Они **не используются** новой версией
и оставлены только для истории: в них есть эталонные вычисления Blender и
неудачные прототипы.

Претензии, которые они не решали:
- тестовый ID 1000002 конфликтует с чужими плагинами;
- предпросмотр оставлял удаляемые грани видимыми;
- цепочки граней давали неманифолдную сетку без предупреждения;
- UV сохраняемых полигонов не переписывались на новые индексы;
- `valid()` вызывался на каждое движение мыши (полное чтение объекта);
- `DrawArrayEnd()` без `DrawArrayBegin()`;
- `kept_marks[idx]=True` в Merge-ветке индексировал укороченный массив.

Новая версия: см. ../BridgeInteractive и ../README.md
