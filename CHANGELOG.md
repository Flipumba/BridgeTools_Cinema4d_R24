# Изменения

## 1.2 — встроенный Bridge как движок

**Проблема.** Плагин отказывался работать с N-гонами и тегами. Это был не баг, а
сознательный отказ собственного движка: он переписывает полигоны сам, а Python API
не даёт описания N-гонов и значений произвольных тегов. Встроенный Bridge
Cinema 4D справляется с этим, потому что он часть программы.

**Что сделано.** Плагин теперь умеет управлять встроенным Bridge через
`SendModelingCommand(ID_MODELING_BRIDGE_TOOL)` (интерфейс описан в SDK Maxon):

- Новый параметр «Движок»: встроенный Bridge (по умолчанию) или собственный.
- Встроенный движок работает с N-гонами и любыми тегами; Undo — одна операция,
  при ошибке изменения откатываются.
- Соответствие вершин подбирается автоматически и передаётся встроенному Bridge
  парой опорных вершин; ручные щелчки по вершинам по-прежнему переопределяют его.
- Параметры диалога передаются во встроенный Bridge: Разрезы → Subdivision,
  Сдвиг соответствия → смещение опорной вершины, Tension, Кривизна, Flip,
  «Удалить исходные грани». Параметры, которых у встроенного Bridge нет
  (интерполяция, профиль, Merge…), серые и работают в собственном движке.
- Режимы «Попарно» и «Цепочка» автоматически идут через собственный движок.
- Если версия Cinema 4D не открывает нужные константы встроенного Bridge,
  плагин сам переходит на собственный движок и пишет причину в углу вьюпорта и в консоли.
- Предпросмотр больше не блокируется N-гонами и тегами; при встроенном движке он
  помечен как приблизительный.
- Ошибка проверки «неманифолдная сетка» при предпросмотре больше не вылетает
  необработанным исключением.

**Тесты.** 88 (было 71): N-гоны и любые теги во встроенном движке, передача
параметров, смещение опорной вершины, откат при сбое, режим рёбер и точек.

**Не проверено.** Работа встроенного Bridge из плагина в реальной Cinema 4D S24 —
см. README, раздел «НЕ проверено».

## 1.1 — мост без выбора вершин

**Главное.** Раньше инструмент не работал без двух щелчков по вершинам кромок
и на Enter просил «выбрать две вершины». В Blender так не делается: Bridge Edge
Loops берёт выделенные петли и сам решает, как их сопоставить. Теперь так же:

- Предпросмотр строится сразу при активации инструмента и при любом изменении
  выделения. Enter или кнопка применяют мост.
- Соответствие вершин подбирается автоматически: перебираются сдвиги кромки B
  (и направление обхода для петель без направления) и берётся вариант с
  минимальной суммой квадратов расстояний между парами. 400 вершин — 14 мс.
- Источник «Авто»: режим Polygons — грани, Edges и Points — рёбра. В режиме
  Points рёбрами считаются рёбра сетки между выделенными вершинами.
- Для парного соединения и цепочек пары и порядок тоже подбираются сами
  (по близости центров кромок, цепочка — кратчайший обход).
- Петли рёбер посреди сетки (по два полигона на ребро) больше не отклоняются:
  направление берётся из геометрии, как в Blender.
- Щелчки по вершинам остались как необязательная ручная подстройка; Esc
  возвращает автоматический вариант. Щелчок мимо вершин больше не открывает
  диалог с ошибкой.
- Причина, по которой мост не строится, пишется в углу вьюпорта.
- Предпросмотр обновляется при смене выделения (раньше следил только за
  числом точек и полигонов).

**Исправлено.** Ручные якоря для замкнутых контуров соединялись со смещением на
одну вершину: якорь первой кромки оказывался в паре с соседом якоря второй.
Теперь якорные вершины действительно соединяются друг с другом.

**Тесты.** 71 (было 55): автоподбор при сдвигах и поворотах, петли без
направления, парный режим, сценарии инструмента без щелчков.

## 1.0 — рефакторинг

### Критические исправления

**Производительность.** `valid()` вызывался на каждое движение мыши и делал
полное чтение объекта (`GetAllPoints` + `GetAllPolygons` + обход всех рёбер).
На плотной сетке это десятки тысяч операций за кадр. Заменено дешёвой подписью
(счётчики точек и полигонов); полная сверка выполняется только перед
применением. Замер: 200 вызовов наведения — 2 мс.

**UV сохраняемых полигонов.** После `ResizeObject` полигоны переезжают на новые
индексы, но UV-тег не переиндексировался. Старые UV оставались на своих
позициях и оказывались привязаны к чужим граням. Теперь сохранённые полигоны
перезаписываются на новые индексы явно.

**Merge нескольких пар.** `kept_marks[idx]=True` индексировал уже укороченный
массив после удаления граней, из-за чего индексы расходились. Логика
переписана на единый построитель `_Builder`, который сразу формирует порядок
«сохранённые, затем новые».

**Вывернутые нормали моста.** Кромка обходится в направлении грани-заглушки, а
полигон моста должен обходить её навстречу. Порядок вершин в полигоне приведён
к `(нижняя_i, нижняя_i+1, верхняя_j+1, верхняя_j)`; проверено на 504
комбинациях параметров.

**Порядок Undo.** `finally: doc.EndUndo(); if failed: doc.DoUndo()` закрывал
транзакцию до отката. Теперь `EndUndo` вызывается один раз, а откат — только
после него и только при зарегистрированном изменении.

**Перетаскивание параметра.** Значение пересчитывалось от `initial` каждый кадр
и клампилось в пределы слайдера, поэтому упиралось в край. Теперь накапливается
смещение, а пределы берутся из диапазона самого параметра.

**Навигация вьюпорта.** `MouseInput` возвращал `True` всегда и глотал вращение.
Теперь не-левые кнопки возвращают `False`.

### Удалено

- `bd.DrawArrayEnd()` без `DrawArrayBegin()` — мусорный вызов в отрисовке.
- Тестовый ID `1000002` → `1055741`.
- Дублирование логики между предпросмотром, отрисовкой и применением: теперь
  все три читают один `Plan`.
- Заглушка `pairs_anchor()` с `AssertionError`.
- Мёртвый код в `_write_hidden`.

### Добавлено

- Режим цепочек рёбер и замыкания последовательности.
- Отклонение объектов с N-гонами и Fields-тегами с понятным текстом.
- Отклонение неманифолдных результатов вместо молчаливой порчи модели.
- Перенос скрытых компонентов и пересчёт UV-закреплений.
- Проверка вывернутых граней, нулевой площади и дубликатов до записи.
- 55 автотестов: 32 геометрия, 23 инструмент.

### Ограничения, зафиксированные явно

- Python API Cinema 4D не даёт доступа к N-гонам — только `GetNgonCount()`.
  Объекты с N-гонами отклоняются.
- Последовательное соединение групп граней даёт неманифолдную сетку, потому что
  кромка уже делится с соседней стенкой. Отклоняется с объяснением. Для рёбер
  цепочки работают.
- Merge с разным числом вершин отклоняется: пересэмплирование изменило бы форму
  сохраняемых полигонов.

### Не сделано

Инструмент **не запускался в реальной Cinema 4D S24.037**. Все проверки — на
имитации API. Для приёмки используйте `c4d_acceptance/run_in_c4d.py`.
