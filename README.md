# Bridge Interactive для Cinema 4D S24

Инструмент по образцу **Bridge Edge Loops** из Blender для Cinema 4D S24.037:
мост по выделению без выбора вершин, автоматическое соответствие кромок,
предпросмотр во вьюпорте и настройки в диалоге инструмента. У него **два движка**:

- **Встроенный Bridge Cinema 4D** (по умолчанию) — сам Bridge Cinema 4D, которым
  управляет плагин. Работает с **N-гонами и любыми тегами**, как обычный Bridge.
- **Собственный** — Blender-подобные Twist, Merge, интерполяция, профиль, цепочки.
  Только треугольники и квады, теги переносит сам.

**Версия:** 1.2 — встроенный Bridge как движок; N-гоны и теги больше не мешают.
**Проверено:** 88 автотестами на имитации API. **В реальной Cinema 4D не запускалось**
— см. раздел «Что проверено, а что нет».

---

## Установка

1. Скопируйте папку `BridgeInteractive` в каталог плагинов Cinema 4D:
   - Windows: `C:\Users\<вы>\AppData\Roaming\Maxon\Maxon Cinema 4D S24_<id>\plugins\`
   - macOS: `~/Library/Preferences/Maxon/Maxon Cinema 4D S24_<id>/plugins/`
2. Перезапустите Cinema 4D.
3. Инструмент появится в меню **Extensions → Bridge Interactive**.
   Если его нет — проверьте консоль (Extensions → Console) на ошибки импорта.

Никаких зависимостей ставить не нужно: чистый Python из состава Cinema 4D.

---

## Быстрый старт

1. Выберите полигональный объект и войдите в режим редактирования.
2. Выделите **две группы граней** (режим *Polygons*) или **две цепочки рёбер**
   (режим *Edges*; в режиме *Points* берутся рёбра между выделенными вершинами).
   Источник определяется по режиму Cinema 4D (поле «Источник» = «Авто»).
3. Выберите инструмент **Bridge Interactive**. Движок по умолчанию — встроенный
   Bridge Cinema 4D. Предпросмотр появляется сразу:
   соответствие вершин между кромками подбирается автоматически — так же,
   как Blender подбирает его у Bridge Edge Loops. Вершины выбирать не нужно.
4. Настройте параметры в диалоге (разрезы, интерполяция, профиль, Merge,
   Twist…) или потяните параметр мышью (**Shift + перетаскивание**).
   Twist смещает соответствие относительно автоматического.
5. **Enter** или кнопка **«Применить мост»** — применить.

Если мост не строится, причина написана в левом верхнем углу вьюпорта
(например, «Выделите ровно две группы граней»). Диалоги с ошибками при
щелчках мимо вершин больше не появляются.

**Какой движок выбрать.** Встроенный — для обычной работы: N-гоны, теги, все
режимы Cinema 4D, Undo одной операцией. Собственный — когда нужны параметры,
которых у встроенного нет (Twist-интерполяция, Merge, профиль, цепочки). Режимы
«Попарно» и «Цепочка» плагин включает на собственном движке сам и пишет об этом
в углу вьюпорта.

**Ручное соответствие (необязательно).** Если автоматически подобранное
соответствие не устраивает, щёлкните вершину на первой кромке, затем
вершину на второй — мост перестроится по ним. **Esc** возвращает
автоматическое соответствие.

## Параметры

| Параметр | Что делает |
|---|---|
| Движок | Встроенный Bridge Cinema 4D или собственный (Blender-подобный) |
| Источник | Авто (по режиму Cinema 4D), грани или рёбра (открытые/замкнутые цепочки) |
| Интерполяция | `Линейная`, `По пути` (кубический Безье с минимальным кручением), `По поверхности` (ручки по нормалям соседних граней) |
| Контуры | Две группы, попарно, цепочка, цепочка с замыканием |
| Разрезы | Число промежуточных колец (0…512) |
| Сдвиг соответствия | Twist: смещение сопоставления вершин по контуру |
| Сглаживание | Изгиб пути между кромками |
| Выпуклость | Радиальное раздутие колец |
| Угол | Закрутка колец вокруг оси моста |
| Форма профиля | Smooth, Sphere, Root, Sharp, Linear, Constant, Inverse Square |
| Merge | Сваривание контуров вместо создания полигонов |
| Положение слияния | Позиция сварки от 0 до 1 |
| Tension, % | Только встроенный: кривизна моста (Tension встроенного Bridge) |
| Кривизна | Только встроенный: Surface / Normal / Surface Average / Normal Average |
| Flip | Только встроенный: разворот моста |
| Удалить исходные грани | Только встроенный: убрать выделенные грани после моста |
| Shift + перетаскивание | Какой параметр менять мышью |

Соответствие параметров. **Разрезы** → Subdivision встроенного Bridge; **Сдвиг
соответствия** → смещение опорной вершины второй кромки; Tension, Кривизна, Flip и
Удалить — одноимённые параметры встроенного Bridge. **Интерполяция, Сглаживание,
Выпуклость, Угол, Форма профиля, Merge** во встроенном Bridge отсутствуют, поэтому
работают только в собственном движке; в диалоге они серые, когда выбран встроенный.

Профиль применяется с огибающей: на концах моста влияние нулевое, в середине —
максимальное. Так же ведёт себя Blender.

## Что проверено, а что нет

### Проверено автотестами (88 тестов)

Геометрия и топология (`tests/test_geometry.py`):
- автоподбор соответствия: при любых сдвигах индексов и поворотах кромки
  мост не перекручен (для произвольных якорей перекрут был в 10 случаях из 12);
- петли рёбер посреди сетки и парное/цепочечное соединение подбираются сами;
- все комбинации разрезов × интерполяции × формы профиля × угла × сглаживания
  дают валидную сетку без вывернутых и вырожденных полигонов;
- Merge сваривает вершины и не оставляет несвязанных точек;
- отклоняются: неманифолдная сетка, выделение с дыркой, ветвящиеся рёбра,
  Merge с разным числом вершин, цепочка граней, дающая неманифолд;
- масштаб не влияет на результат (миллиметры и километры);
- валидатор ловит вывернутые грани, нулевую площадь и дубликаты.

Инструмент целиком (`tests/test_tool.py`):
- предпросмотр появляется при активации инструмента, без щелчков;
- Enter применяет мост без выбора вершин, Undo откатывает одной операцией;
- смена выделения и режима Cinema 4D обновляет предпросмотр;
- щелчок мимо вершин не вызывает диалогов;
- два клика (ручное соответствие) → предпросмотр без изменения объекта;
- подсветка кандидата, отрисовка поверхности и удаляемых граней;
- Esc сбрасывает выбор и не трогает объект;
- применение создаёт ровно одну операцию Undo, Undo восстанавливает геометрию;
- UV-тег растёт вместе с числом полигонов, сохранённые полигоны сохраняют UV;
- Vertex Map совпадает по длине с числом вершин;
- закреплённые UV-точки пересчитываются на новые индексы;
- объекты с N-гонами, Fields-тегами и неизвестными тегами отклоняются без изменений;
- смена выделения сбрасывает контекст;
- навигация вьюпорта не перехватывается;
- перетаскивание параметра не упирается в край экрана, Esc возвращает значение;
- режим рёбер: две открытые цепочки, мост поверх существующих полигонов.

Падение геометрии: 200 вызовов наведения на сетке — 2 мс; предпросмотр на
3600 полигонах — 42 мс; применение — 32 мс.

### НЕ проверено

**Инструмент не запускался в реальной Cinema 4D S24.037.** В этой среде
Cinema 4D нет, поэтому не проверены:

- **встроенный Bridge из Python**: имена параметров и то, как именно Cinema 4D
  истолкует пару опорных вершин и режим островов в вашей версии. Плагин при запуске
  печатает в консоль, какие константы доступны, а при их отсутствии сам переходит на
  собственный движок и пишет об этом;
- регистрация плагина и появление в меню;
- реальная работа `ToolData`: `Draw`, `GetCursorInfo`, `MouseInput`;
- фактическое поведение `BaseDraw.WS`, `DrawPolygon`, `DrawHandle`;
- `MouseDragStart` / `MouseDrag` / `MouseDragEnd` в интерактивном цикле;
- `doc.StartUndo` / `AddUndo` / `DoUndo` в настоящем документе;
- запись `UVWTag.SetSlow` и `SetPinSelection` на живом теге;
- поведение на реальных моделях с нестандартной топологией.

**Не запускайте на оригинальных проектах.** Сначала копия файла.

## Осознанные ограничения

### Собственный движок: N-гоны, Fields, неизвестные теги

Собственный движок переписывает полигоны сам, поэтому он отказывается от того,
чего не умеет переносить без риска порчи данных: объектов с N-гонами, тегов с
включёнными Fields и неизвестных типов тегов. Сообщение подсказывает перейти на
**встроенный** движок, у которого этих ограничений нет: топологию и теги там ведёт
сама Cinema 4D.

### Встроенный движок: что он не умеет

- Только режим «Две группы». Попарно и цепочка идут через собственный движок.
- Предпросмотр во вьюпорте **приблизительный**: его строит собственный движок.
  Окончательную форму моста строит встроенный Bridge (разрезы, Tension, Кривизна).
- Twist-интерполяция, профиль и Merge недоступны: у встроенного Bridge их нет.
- Жест «протянуть линию от вершины к вершине» из встроенного инструмента не
  повторён: соответствие подбирается автоматически, а вручную задаётся двумя
  щелчками по вершинам.

### Цепочки граней: отклоняются

Последовательное соединение трёх и более **групп граней** в Cinema 4D
невозможно без неманифолдной сетки. Кромка группы граней уже делится с
соседней стенкой; второй мост на той же кромке даёт три полигона на ребро.

Blender позволяет цепочку потому, что работает с одномерными петлями рёбер,
у которых кромка свободна. Поэтому здесь:

- цепочки и замыкание **реализованы для цепочек рёбер** (режим «Источник: рёбра»);
- для групп граней цепочка отклоняется с объяснением, а не портит модель.

### Другие ограничения

- Собственный движок: только треугольники и квады (см. выше).
- Merge требует одинакового числа вершин в контурах. Пересэмплирование
  недопустимо: оно изменило бы форму сохраняемых полигонов.
- Глобальное самопересечение сетки не проверяется: дорого и даёт ложные
  срабатывания. Проверяются локальные свойства новых полигонов.

## Сохранность данных

- Исходный объект не меняется до подтверждения: предпросмотр работает на
  копии точек.
- Изменение выполняется одной операцией Undo; при ошибке документ
  откатывается через `DoUndo`.
- UV переносятся с учётом швов: новый полигон берёт UV той стороны шва,
  с которой он стыкуется.
- Сохранённые полигоны перезаписываются на новые индексы, иначе UV
  оказались бы привязаны к чужим граням.
- Vertex Maps интерполируются по уровням моста; при Merge — смешиваются
  по фактору.
- Выделения полигонов, точек и рёбер переносятся по парам вершин, а не по
  сырым индексам (сырой индекс ребра после удаления граней указывает на
  другой полигон).
- Скрытые компоненты (`GetPointH`, `GetPolygonH`, `GetEdgeH`) сохраняются.

## ID плагина

`1055741`. Это не служебный диапазон Maxon и не `1000002` из предыдущей
версии, который конфликтовал с чужими плагинами. Для публикации получите
официальный ID в личном кабинете Maxon. Значение задаётся одной строкой
`PLUGIN_ID` в начале `bridge_interactive.pyp`.

Если при загрузке появляется `RuntimeError: Could not initialize global resource`,
причина — не ID, а отсутствие в `res/` файлов `c4d_symbols.h` и
`strings_us/c4d_strings.str`. Они входят в плагин, их нельзя удалять.

## Структура

```
BridgeInteractive/
  bridge_interactive.pyp   точка входа, ToolData
  bridge_math.py           векторы, профили, кадры пути (без c4d)
  bridge_topology.py       острова граней, цепочки, сшивание
  bridge_plan.py           планировщик операции (единственный источник истины)
  bridge_validate.py       проверка результата до записи
  bridge_data.py           перенос UV, весов, выделений
  bridge_host.py           слой Cinema 4D: чтение, запись, Undo
  bridge_dialog.py         интерфейс инструмента
  res/icon.png
  res/c4d_symbols.h        глобальный ресурс (обязателен для R24)
  res/strings_us/, strings_ru/  пустые таблицы строк (обязательны)

tests/
  mock_c4d.py              имитация API
  test_geometry.py         32 теста геометрии и топологии
  test_tool.py             23 теста инструмента
  run_all.py               общий запуск

c4d_acceptance/
  run_in_c4d.py            приёмочный скрипт для реальной Cinema 4D
```

Ключевое архитектурное решение: **предпросмотр, отрисовка и применение
читают один `Plan`**. Раньше эти три места дублировали логику, и именно там
расходились результаты (например, при Merge нескольких пар).

## Если что-то не работает

Откройте **Extensions → Console** и пришлите текст ошибки. Наиболее вероятные
места при первом запуске в реальной Cinema 4D:

1. `BaseDraw.WS` возвращает координаты в другой системе — тогда подсветка
   будет смещена. Правится в `pick()`.
2. `MouseDragStart` требует других флагов — правится в `drag_parameter()`.
3. `UVWTag.SetSlow` после `ResizeObject` может вести себя иначе — правится
   в `_write_uv()`.

Все три места локализованы в одном файле каждый.

При активации инструмента плагин печатает в консоль строку вида
`[Bridge Interactive] встроенный Bridge доступен…` или список отсутствующих
констант. Пришлите её вместе с текстом ошибки, если мост не строится.
